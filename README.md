# WebAR — практическая работа

## Открыть на телефоне

Готовый сайт с HTTPS: https://fancybear01.github.io/webar-mindar/

Задание 3 с очками: https://fancybear01.github.io/webar-mindar/mindar-face-tracking.html

Откройте ссылку в Chrome на телефоне и разрешите камеру. Для опубликованного сайта ноутбук, локальный сервер и настройка `chrome://flags` не требуются.

Стартовая страница `index.html` содержит шесть заданий:

1. `model-viewer-ar.html` — 3D-пирамида и размещение через AR-просмотрщик.
2. `mindar-image-tracking.html` — пирамида над изображением `assets/marker.png`.
3. `mindar-face-tracking.html` — 3D-очки, следующие за лицом через MindAR Face Tracking.
4. `threejs-hit-test.html` — WebXR hit-test и размещение куба на найденной плоскости.
5. `threejs-controls.html` — управление цветом, поворотом, моделью и PBR-материалом, HDRI-освещение.
6. `unity-viewer/` — настоящая WebGL-сборка Unity с De-Panther WebXR Export и кубом в viewer-space.

## Задание 5: проверка на телефоне

Откройте https://fancybear01.github.io/webar-mindar/threejs-controls.html в Chrome на Android.

1. До запуска AR проверьте переключение куба, пирамиды и узла, цвет и кнопки поворота.
2. Ползунок «Металличность» меняет metalness, «Шероховатость» — roughness. Свет и отражения берутся из настоящей карты `assets/studio.hdr`, подготовленной через PMREM.
3. Нажмите «Начать AR», разрешите камеру. Медленно направляйте телефон на освещённую фактурную поверхность, пока не появится зелёное кольцо.
4. Нажмите «Поставить объект». Откройте «Настроить объект»: цвет, модель и вращение меняются прямо в AR, положение объекта сохраняется.
5. Сверните настройки и обойдите объект. Он должен оставаться в точке размещения, а не двигаться за телефоном.

AR требует Android с ARCore и поддержку WebXR hit-test и DOM Overlay. На несовместимом устройстве остаётся обычный 3D-просмотр. Кнопки защищены от AR-события выбора (`beforexrselect`): нажатие настройки не должно случайно переставлять объект.

Код разделён на классы в `modules/task5/`: `SceneController` создаёт сцену, `ObjectManager` загружает и изменяет модели, `EnvironmentLighting` загружает HDRI, `XRPlacement` управляет AR и hit-test, `UIController` обрабатывает интерфейс. `main.js` — точка входа. Three.js и его загрузчики сохранены локально, CDN для задания 5 не нужен.

Автоматическая проверка `tools/check_task5.cjs` проверяет реальную загрузку HDRI и glTF, материалы, интерфейс и размещение с имитацией WebXR. Она не заменяет тест камеры и трекинга на настоящем Android.

## Задание 6: Unity

Исходный Unity-проект расположен рядом с локальной копией сайта, в папке `../webar-unity-task6`. На GitHub Pages доступен [архив исходников Unity](downloads/unity-task6-source.zip). В нём сохранён настоящий пакет De-Panther WebXR Export 0.25.0, WebXR-шаблон и C#-скрипты подготовки сцены и сборки.

Готовая WebGL-сборка Unity: https://fancybear01.github.io/webar-mindar/unity-viewer/.

Откройте в Chrome на Android, дождитесь загрузки и нажмите «Начать AR». После разрешения камеры куб должен находиться перед ней и следовать за телефоном. Это специально отличается от заданий 4–5, где объект фиксируется на поверхности.

Сборка выполнена Unity 6000.3.7f1 с WebXR Export 0.25.0. Compression Disabled, decompression fallback false, multithread false. Размер файлов: 16 686 623 байта (16,69 МБ / 15,91 МиБ). Модуль WebGL установлен, проблема лицензии устранена.

Проверены реальная загрузка WASM, запуск C#-сцены и отображение куба в настольном Chrome, WebXR bridge с пространством `viewer` и интерфейс на узком экране. `tools/check_task6.cjs` повторяет эту проверку. Мобильная камера и immersive-ar ещё требуют теста на настоящем Android; настольная проверка не подтверждает их работу.

## Запуск

В PowerShell из этой папки:

```powershell
python -m http.server 8080
```

Для проверки на компьютере откройте `http://localhost:8080`. Для проверки с телефона откройте временную HTTPS-ссылку, созданную в другом PowerShell:

```powershell
cloudflared tunnel --url http://localhost:8080
```

Оба терминала должны оставаться открытыми. Телефон и ноутбук можно подключить к одной сети Wi-Fi. Для задания 3 разрешите доступ к передней камере. Для задания 4 нужен Android Chrome с поддержкой WebXR и установленные Сервисы Google Play для AR.

## Что проверить

- Задание 3: очки появляются на лице, следуют за поворотом и наклоном головы, исчезают при потере лица и возвращаются после повторного обнаружения.
- Задание 4: после «Начать AR» появляется зелёное кольцо на полу или столе; касание размещает куб. При перемещении телефона куб остаётся на прежнем месте.

Файлы A-Frame, MindAR, Three.js, MediaPipe WASM и модель лица сохранены локально. Камера и WebXR требуют HTTPS либо `localhost`. Настольная проверка подтверждает загрузку страницы и сообщения о совместимости, но не заменяет проверку AR на телефоне.
