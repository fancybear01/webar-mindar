# WebAR — четыре практических задания

Статический сайт для проверки WebAR на телефоне. Публикуется через GitHub Pages с HTTPS.

- `model-viewer-ar.html` — просмотр пирамиды и размещение модели в AR.
- `mindar-image-tracking.html` — пирамида появляется над изображением-маркером.
- `mindar-face-tracking.html` — 3D-очки на лице с MindAR Face Tracking.
- `threejs-hit-test.html` — размещение куба на поверхности через Three.js и WebXR.
- `camera-check.html` — диагностика защищённого контекста и передней камеры.

Откройте сайт в Chrome на Android и разрешите доступ к камере. Для задания 4 телефон должен поддерживать WebXR immersive AR и Google Play Services for AR. Для задания 3 ARCore не требуется.

Маркер для задания 2: `assets/marker.png`. Его нужно показать камере на другом экране или распечатать.

Видеопоток обрабатывается в браузере и не отправляется на сервер.
